# Data

The raw video dataset is **not included** in this repository (too large).
The trained model in `models/` works without it — you only need data to
re-train.

## Layout

```
data/
├── raw/          # INPUT: one folder per sign, containing .mp4 clips
│   ├── eat/
│   │   ├── 1 (1).mp4
│   │   ├── 1 (2).mp4
│   │   └── ...
│   └── ...
├── landmarks/    # generated by step1  → <sign>/<clip>.mp4.npy, shape (60, 258)
└── split/        # generated by step2  → train/ val/ test/
```

## Clip naming (important)

`step2_split_dataset.py` does a **person-aware split** based on the file name:

```
<person_id> (<clip_number>).mp4      e.g.  3 (12).mp4
```

- Persons **1–4** → training set
- Person **5** → held out, split 50/50 into validation and test

Files that don't match this pattern are skipped.

## Signs (24 classes)

`I, come, eat, friend, go, good, help, home, learn, like, morning, no,
noclass, phone, please, salam, school, sorry, student, teacher, thankyou,
want, water, you`

`noclass` is a "no sign / idle" class used to reject background motion.
